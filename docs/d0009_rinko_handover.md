## A. 追加で検証すべきこと

### A1. 質問者を複数にした評価（優先度：高）

- 現状：質問者は受信箱を持たない 1 台に固定した．負荷の測定も，質問者 1 台が同時に 30 問を送り続ける条件である．

  - 障害：質問者は停止した PC を問い合わせ先から外す仕組みを持たないので（B1），質問者の数だけ待ちが生じないか．
- 報告書の今後の課題には入れていない（質疑で出た論点）．

### A2. 「わからない」を許す指示をやめたことによる作り話の評価（優先度：高）

- 現状：受信箱ごとの回答の生成で「わからない」と答えてよいとする指示をやめると，P2P 構成の正答率は 0.0248 上がった（主構成）．この値は再実行による変動を含む．
- 懸念：資料に答えが無い受信箱（持ち主でない受信箱）も何か答えるので，作り話が増える可能性がある．正答率は「わからない」と誤答をどちらも不正解として数えるので，作り話の増減が見えない．
- 確かめること：
  - 回答を「正解・わからない・誤答」に分けて，指示の有無で集計する．
  - 持ち主でない受信箱の回答に，作り話がどれだけ含まれるかを数える．
  - 最終的に選ばれた回答に作り話が残る割合を見る．選択は質問と候補の文脈だけで決まり回答の文には依らないので，持ち主でない受信箱の作り話は選ばれにくいと推測しているが，確かめていない．
- 報告書の限界（第 7.2 節）にも，スライドの p.25 にも書いていない（質疑で出た論点）．
- 着手：Iteration 21（事前登録は journal の Iteration 21）．
- 完了：Iteration 21（2026-11-06．採用）．結果は `results/d0009_a2_fabrication/`（`verdict.json`・`fabrication.json`・`dev/`・人手での確かめ `manual_check/`），記述は `.claude/research/journal.md` の Iteration 21．判定（p0007 の test 2,939 問．A5＝指示あり・R3 対 A6＝指示なし・R3′）：
  - 持ち主でない受信箱の回答の作り話の割合は 0.157 → 0.361 に増えた（差 +0.205．95% 区間 0.193〜0.216）．
  - 最終的に選ばれた回答の作り話の割合は 0.197 → 0.195 で，再実行の変動の幅（0.02）を超えては変わらない（差 −0.002．−0.015〜+0.010）．候補を一様に選んだ場合（0.298）より 0.103 低く，選択は作り話を避けている．
  - 指示をやめた分の正答率の上がりは，選ばれた回答の「わからない」が減った分（0.051 → 0.031）にあたる．作り話が増えるのは持ち主が候補に入らない問（区分 (a)）に限られる（0.497 → 0.575）．
  - 制約：設計に使った test での記述（C1），選択はオフラインの当てはめ（C2），人手での確かめは agent 1 人で 200 件（一致率 0.93・κ 0.86）．

### A3. 差の信頼区間に再実行の変動を含める（優先度：高）

- 現状：差（−0.0235）の 95% 信頼区間は質問のブートストラップだけで求めた．cross-encoder を加える前の構成を再実行したときの正答率の変化は +0.0078（95% 信頼区間の上端 +0.0173）で，差の一部が変動による可能性がある．
- 確かめること：同じ構成を複数回実行し，変動を含めた区間で非劣性（δ = 0.02）を判定し直す．δ は判定規則を記録した時点の変動の最大値 0.006 の約 3 倍として決めたので，変動の測り直しで δ の根拠も見直す．
- A2 との関係：A2 の指示の有無の比較（選ばれた回答の作り話の差 −0.002，正答率の差 +0.022）は再実行の変動と分けられていない．ここで測った変動で読み直せる．
- 着手：Iteration 22（事前登録は journal の Iteration 22．設計の判断は `.claude/research/backlog.md` の B79）．
- 完了：Iteration 22（2026-11-08．採用）．結果は `results/d0009_a3_rerun_variance/`（`verdict.json`・`rerun_variance.json`・ゲート `g0_g3.json`・`g1/`・`g2.json`・`g-e.json`・`g-j.json`），実行は `results/d0009_a3_{p1,p2,p3,c1,c2,c3}/` と R3′ の当てはめ `results/d0009_a3_p{1,2,3}_R3p/`，記述は `.claude/research/journal.md` の Iteration 22．判定（新しく分けた質問 H．test の受信箱ごとの 21〜40 番目の 2,860 問．P2P-R3′ と C1-RRF-CE を 3 回ずつ交互に実機で流した）：

  - 再実行の変動は小さく（同じ構成の正答率の差の最大は P 0.001，中央 0.006），変動を含めても区間の幅は 1 回の実行の区間と同じ（比 0.993）．中央の 1 組だけ McNemar の p = 0.046 で，変動が独立な回答の変化だけとは言い切れない．

  - 制約：選択と中央の再ランクはオフライン（gpu4）での当てはめ（C2），判定モデルは test の採点と一致率 0.89〜0.91 で，H と test の正答率の水準は比べられない．
